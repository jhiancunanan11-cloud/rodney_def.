# Registrar's Office Dashboard (Flutter)

A responsive Flutter UI inspired by the supplied screenshot.

## Run it

1. Install Flutter SDK and set up an emulator, or enable web/desktop support.
2. Open a terminal in this folder.
3. Run:

   ```bash
   flutter pub get
   flutter run -d chrome
   ```

   Or use `flutter run` for an emulator/device.

## Notes

- Main UI code: `lib/main.dart`
- Uses Flutter Material icons and no external packages or image assets.
- Navigation/action buttons currently show demo SnackBars. Connect them to your backend/routes to make them functional.
- Sample student name, appointment data, and transactions are demo data.
